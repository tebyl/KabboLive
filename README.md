# Kabbo Hotel — v0.1.0-demo

Demo local de un juego social isométrico. Decora habitaciones, camina con tu avatar, chatea con el bot guía y completa misiones para ganar créditos.

## Estado

Prototipo offline/local — sin multijugador ni servidores. Desarrollado con Godot Engine 4.

## Controles rápidos

| Tecla | Acción |
|---|---|
| Click izquierdo | Caminar / Colocar mueble |
| Tab | Exploración ↔ Decoración |
| B | Tienda |
| S / L | Guardar / Cargar |
| Escape | Cerrar panel / Menú pausa |
| H | Tutorial |
| O | Configuración |
| F1 / F2 / F3 | Cambiar sala |

Consulta [docs/TESTER_GUIDE.md](docs/TESTER_GUIDE.md) para la guía completa.
